## 📋 التعديلات المنفذة لرفع المشروع على GitHub Pages

تم إعادة تنظيم المشروع ليعمل بشكل صحيح على GitHub Pages وفقاً للمتطلبات التالية:

### ✅ التعديلات المنفذة:

1. **تغيير أسماء الملفات:**
   - ❌ ~~`login.html`~~ → ✅ **`index.html`** (الواجهة الرئيسية للتسجيل)
   - ❌ ~~`منصة_IEP.html`~~ → ✅ **`iep.html`** (منصة الخطة التربوية)

2. **تعديل توجيه تسجيل الدخول:**
   - تم تحديث الكود في `index.html` ليوجه المستخدم إلى `iep.html` بعد تسجيل الدخول بنجاح
   - تحديث السطر 557: `iframe.src='iep.html';`

3. **تعديل PWA Manifest:**
   - تم تحديث `start_url` من `'./منصة_IEP.html'` إلى `'./iep.html'`
   - السطر 681 في ملف `index.html`

## 🚀 خطوات الرفع على GitHub Pages

### 1. إنشاء مستودع جديد على GitHub
1. اذهب إلى [GitHub](https://github.com)
2. اضغط على **New Repository**
3. اسم المستودع: مثلاً `iep-platform`
4. اختر **Public**
5. اضغط **Create Repository**

### 2. رفع الملفات
يمكنك رفع الملفات بإحدى الطريقتين:

#### الطريقة الأولى: عبر واجهة GitHub (الأسهل)
1. افتح المستودع
2. اضغط **Add file** → **Upload files**
3. اسحب الملفين (`index.html` و `iep.html`)
4. اضغط **Commit changes**

#### الطريقة الثانية: عبر Git Command Line
```bash
git init
git add index.html iep.html
git commit -m "Initial commit - IEP Platform"
git branch -M main
git remote add origin https://github.com/username/iep-platform.git
git push -u origin main
```

### 3. تفعيل GitHub Pages
1. اذهب إلى **Settings** في المستودع
2. اختر **Pages** من القائمة الجانبية
3. في **Source**، اختر **main** branch
4. اضغط **Save**
5. انتظر دقيقة، ثم ستظهر رابط الموقع: `https://username.github.io/iep-platform/`
